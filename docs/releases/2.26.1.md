# Coflux 2.26.1

**A finished agent turn you looked at on one device no longer celebrates on the others.**

In 2.26.1:

- **"Seen" follows you across devices.** When an agent finishes its turn, Clawd throws confetti until you look at that terminal. Looking at it on the Mac now stops the confetti on the iPhone too, and the other way round; the next finished turn celebrates again. The center keeps this mark in memory only, so a center restart can bring one round of confetti back.
- **The sidebar's agent rows show Clawd.** The rows at the top of the desktop sidebar now lead with the same agent glyph as the terminal tab (Clawd working, raising a flag when it waits for you, celebrating when it finished, standing once you have looked; the Codex logo or a robot, tinted by status, for other agents), and the separate status dots are gone.

## iOS app

The iOS app is released on its own line. Its build with this source also stops celebrating turns you looked at on another device, and on iPhone Duo the inner display, opened tall, types on a full-size Mac-layout keyboard.

## Install or update

**Mac:** install `coflux-2.26.1-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.26.1
cofluxd update
```

## Upgrade impact

- The center was updated before this release; there is no database migration.
- Older desktop and iOS builds keep working against the updated center; they simply keep tracking "seen" on their own device.
- Devices and headless hosts need no action: the runtime only gained the new protocol field, which it never sets.
