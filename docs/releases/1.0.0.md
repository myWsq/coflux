# Coflux 1.0.0

**One workspace for your terminals, your machines, and your coding agents.**

Coflux 1.0 brings the desktop app, command-line tools, and terminal runtime together as one product. Connect your Macs and Linux development hosts to the same account, work across their repositories, and give agents access to terminals you can inspect and take over.

## Highlights

- **A self-contained Mac app.** Install Coflux, sign in, and start a local terminal. The app includes its runtime and native CLI; no separate Node.js or CLI installation is required.
- **Clear command-line roles.** `cofluxd` manages a headless host. `coflux` handles sign-in, devices, workspaces, and local or remote terminals. The desktop app injects the same `coflux` command into its terminals.
- **Visible agent workflows.** Agents can open terminals, read output, send input, report progress, and request your attention. Human takeover takes priority over agent input.
- **Terminal-preserving client updates.** Ordinary app updates reconnect to the running runtime. Worker updates keep the same terminal processes alive; Supervisor updates can wait until your tasks finish.
- **An explicit desktop lifecycle.** Closing a window keeps the device online. Fully quitting or signing out asks for confirmation and ends local terminals. Signing out clears this device's session data without deleting project files or other devices' terminals.
- **One release version.** Desktop, npm tools, and runtime artifacts now ship under the same version and GitHub release.

## Install

**Mac:** download `coflux-1.0.0-arm64.dmg`, open it, and drag Coflux to Applications. Requires **macOS 26+ and Apple Silicon**. The release app is Developer ID signed and notarized.

**Linux or headless hosts:** install Node.js 20+, then run:

```sh
npm install -g cofluxd@1.0.0
cofluxd up
```

Follow the authorization link to connect the host. The npm package includes both `cofluxd` and `coflux`.

## Upgrading from 0.x

This release intentionally simplifies the command surface:

- Replace `cofluxd login`, `cofluxd workspace`, `cofluxd terminal`, and other operation commands with **`coflux`**.
- Keep **`cofluxd`** for `up`, `down`, `status`, `doctor`, `logs`, `update`, and `restart`.
- Update custom agent hooks to invoke `coflux hook`. The bundled Claude Code plugin already uses the new command.
- The MCP server and its dedicated OAuth flow have been removed. Use `coflux` for local, cross-workspace, and cross-device automation.
- Desktop releases now use **`v1.0.0`**, not a separate `desktop-v*` version. Existing desktop installations keep their update feed.

An app or CLI update does not require restarting the terminal holder. Restarting the Supervisor or operating system ends live terminal processes; finish your tasks before applying that kind of runtime update. Legacy system-service migration is an explicit action rather than a silent restart.

## Release contents

- macOS desktop DMG, update ZIP, and update metadata.
- Runtime binaries for Linux x86_64/ARM64 and macOS x86_64/ARM64, signed runtime manifests, and checksums.
- Linux relay binaries for self-hosted infrastructure.
- Matching `cofluxd@1.0.0` on npm, containing both command-line entry points.

The standalone runtime's macOS x86_64 build does not imply an Intel desktop app. iOS source is available in the repository, but an iOS app is not included in this release.
