# Coflux 2.25.0

**Dictate into any desktop terminal, and let a language model fix the mixed Chinese/English terms the recogniser gets wrong.**

In 2.25.0:

- **Dictation on the desktop.** Every terminal pane has a microphone button in its bottom-right corner. Click it, or press Option-Space in the focused terminal, and speak: the text types itself out in a bubble above the button. Click again or press Option-Space to stop; hold Option-Space to talk and release to stop. The bubble then becomes editable: Return sends the text to the terminal and presses Enter, Command-Return inserts it without Enter, and Escape discards it. The button appears only when speech recognition is configured for the account, and the app asks for microphone access the first time.
- **Correction after recognition.** The Speech recognition settings, on the desktop and in the iOS app, have a new optional section for an OpenAI-compatible chat model (base URL, model, API key). When it is on, the recognised text goes to that model with the workspace's file names and the agent's recent conversation, and only misheard technical terms are corrected: rebase, main, worktree and your own project's names come back spelled right. The correction is bounded to about three seconds; if it does not answer in time, you get the recognised text unchanged. The confirm step can show the original text whenever the correction changed something.
- **Fuller recognition context.** Dictation now reads the agent conversation with tool output filtered out on the device and adds the terms the agent has been working with, so the recogniser itself hears more of your project's vocabulary.
- **The sidebar opens on what you are working on.** A section at the top of the desktop sidebar lists the workspaces with recent activity and the ones you visited last; projects remember whether they are expanded. Command-Shift-A jumps to the next workspace waiting for you.

## iOS app

The iOS app is built from source and is not part of this release's downloads. This version of the source adds correction after recognition and the fuller recognition context to dictation, and reworks the sidebar on iPhone Duo (account and devices in the sidebar, a floating sidebar on the inner display, a settings page).

## Install or update

**Mac:** install `coflux-2.25.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.25.0
cofluxd update
```

## Upgrade impact

- The center was updated before this release. It adds migration 13, which stores the correction settings; the migration is one-way, so an older center does not start on the migrated database.
- API keys stay write-only and encrypted on the account. On the desktop they are used only by the app's main process and never reach the window's page.
- The desktop app now carries the macOS microphone entitlement; macOS asks for access the first time you dictate.
- Older desktop and iOS builds keep working against the updated center; they simply do not see the correction settings.
- Devices and headless hosts need no action: the runtime is unchanged apart from its protocol definitions.
