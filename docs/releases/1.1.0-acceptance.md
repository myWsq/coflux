## Artifact verification

All 40 assets were downloaded. Their byte counts and SHA-256 digests matched GitHub metadata; every SHA256SUMS entry matched. All 12 supervisor/worker/CLI artifacts across four targets passed release-statement verification using the repository's public key. The desktop ZIP SHA-512 matched both the release metadata and the live desktop update feed.

The extracted desktop app reported version 1.1.0, passed strict/deep codesign verification and Gatekeeper assessment with `source=Notarized Developer ID`. Its stapled notarization ticket validated. The workflow staples the app before creating the DMG/ZIP; the outer DMG itself has no stapled ticket. The bundled native CLI signature also validated.

The downloaded release CLI passed native Claude Code 2.1.269 and Codex CLI 0.154.0 acceptance in isolated temporary homes: loading, native Codex review, unrelated user hooks, resumed context, native compaction, and renewed review after a changed executable. No real user agent configuration or model account was used.

The npm tarball matched registry integrity:

sha512-gVqKo1bBaNCi2QzLt0+0/BqNBsZTyfJMT5Df0aChzLSD67EMSijT5lYNYQhZDth35n1NaB4VRj6na09EH1uCHQ==

Using the published npm package in an isolated COFLUX_HOME, `cofluxd update --version v1.1.0` downloaded and verified all three native macOS ARM64 components. The packaged `coflux agent prepare` entry successfully invoked the installed native CLI and generated its immutable integration directory. No real service was installed or restarted.

## Validation repair

The initial main CI run exposed an existing test-helper race: a rejected CLI command could close stdin before the helper finished writing, producing an unhandled EPIPE. The helper now accepts that closure, waits for output streams to close, and retains the exit-code/output assertions. Local full regression passed 215/215; subsequent main, release and npm quality gates passed.

npm initially returned stale registry metadata briefly after successful publication. Acceptance waited until the exact version, latest tag and actual package download were available. Publication success alone was not treated as registry acceptance.

First-time shell activation still requires the updated terminal runtime and a new shell, or an explicit `coflux agent run` invocation. Existing user terminals and daemons were not restarted as part of this release acceptance.
