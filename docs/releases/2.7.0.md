# Coflux 2.7.0

**A desktop-only change: ⌘T now asks what to open, a terminal or a browser tab.**

Nothing in the center or the runtime changes. Install the desktop app; daemons on other machines need no action.

## Highlights

- **⌘T opens the new tab menu.** ⌘T used to create a terminal right away. It now opens the same menu as the plus at the end of the focused tab strip, with the first item already selected: press Return for a terminal, or the arrow keys and Return for a browser tab. Escape (or ⌘T again) closes the menu and puts the cursor back where it was. The menu items themselves have no shortcut. ⌘T works the same way while a web page in a browser tab has focus.
- **The File menu follows.** Its ⌘T item now opens the same menu; creating a terminal and creating a browser tab remain there as separate items without a shortcut. The keyboard shortcut overview (⌘/) and the empty terminal group's hint describe the new behavior. The button in an empty group still creates a terminal directly.

## Install or update

**Mac:** install `coflux-2.7.0-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:** this release contains no runtime changes, so there is nothing to update. The packages are published at the same version for consistency:

```sh
npm install -g cofluxd@2.7.0
cofluxd update
```

## Upgrade impact

**⌘T changes meaning.** Opening a terminal from the keyboard is now ⌘T then Return instead of ⌘T alone. No schema migration, no server configuration, and no daemon capability is involved. A machine running 2.6.x daemons works unchanged with the 2.7.0 desktop app.
