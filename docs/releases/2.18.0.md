# Coflux 2.18.0

**Terminals you are not looking at no longer cost CPU or battery.**

Until now, every terminal that printed anything sent a full copy of its screen and history through the Coflux server every two seconds, and the desktop app re-drew that copy in every hidden tab, even with the window hidden. With a few dozen long-running agent sessions this kept the desktop app at about 10% CPU and near the top of macOS's energy list.

In 2.18.0:

- A terminal's title and command state reach the server the moment they change, and its screen is saved only once its output settles, at most every 30 seconds while it keeps printing.
- The desktop app receives titles only. It loads a terminal's screen only for a tab you are looking at that is not live on this Mac: one another device has taken over, or one whose device is offline. A tab taken over by another device still refreshes about every two seconds.
- A terminal's last screen is saved right before it exits, so an ended terminal still shows what it printed last.
- Git change counts for a workspace are checked less often while they stay the same, up to once a minute, and right away again when they change.
- The sidebar no longer redraws every three seconds when nothing changed, and finished status icons no longer animate.

Nothing changes in how you use Coflux.

## Install or update

**Mac:** install `coflux-2.18.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.18.0
cofluxd update
```

## Upgrade impact

- The center was deployed before this tag. No schema migration and no new configuration.
- The server pushes the new runtime to connected devices as usual.
- Older desktop apps and the iOS app keep working unchanged. Their view of a terminal they are not attached to now refreshes when the terminal's output settles, at most every 30 seconds, instead of every two seconds.
