# Coflux 2.29.0

**Agents can show you an HTML page: a canvas opens as a tab in the desktop app, and you answer by annotating it.**

In 2.29.0:

- **`coflux canvas show <file.html>`.** An agent working in a Coflux terminal shows a mockup, a comparison of options or the result of some research as a page instead of describing it. The command returns at once; files beside the page (stylesheets, images, fonts) load too.
- **The page opens in the background.** The desktop adds a tab to that workspace without taking focus and marks it with a dot until you look at it. Showing the same file again reloads the same tab.
- **Feedback is an annotation or a sentence.** A canvas is a built-in browser tab, so you point at elements or drag a region and comment as on any page; the agent reads them with `coflux annotations list`. There is no approve button: say what you think in the conversation.
- **Canvases stay reachable.** The new-tab menu (the plus button, or Cmd+T) lists the workspace's canvases with when each was last shown. A canvas whose file is deleted leaves the list.

## Install or update

**Mac:** install `coflux-2.29.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.29.0
cofluxd update && cofluxd restart
```

## Upgrade impact

- A canvas needs all three parts: the center (already deployed), this runtime on the device the agent runs on, and this desktop app. An older desktop ignores canvases; an older runtime has no `canvas` command.
- The runtime changed; the center pushes it to devices automatically and terminals keep running. The CLI gained the `canvas` command, so headless hosts run the update above to get it. `ptyd` is unchanged.
- The runtime serves canvases on loopback port 8795 of its device, to local processes only. If another program holds that port, canvases are unavailable on that device and `coflux canvas show` says so; set `COFLUX_CANVAS_PORT` for the runtime to move it.
- A canvas serves the whole directory of its HTML file to local processes that know its address. Agents are told not to place a canvas beside secrets.
- No schema migration.
- The Claude Code plugin (0.27.0) documents canvases for agents. Agent sessions started before the update keep the previous instructions.
- The iOS app only receives regenerated protocol code; it does not show canvases yet.

## Known limits

- On a remote device whose connection cannot carry the page, a canvas tab currently stays blank instead of showing an error.
- The unread dot is not kept across a restart of the desktop app.
