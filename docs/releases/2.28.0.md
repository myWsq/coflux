# Coflux 2.28.0

**The desktop sidebar's three sections are now resizable panes: drag the dividers, VS Code style.**

In 2.28.0:

- **Drag the sidebar's section dividers.** The current-agents, projects and devices sections are explicit panes with draggable dividers between them. Dragging moves space between the two adjacent panes only, each pane keeps at least its header and a row, and the sizes persist across restarts. Double-click a divider to reset that pair to its default ratio.
- **Each section scrolls on its own.** The current-agents section is pinned above the project tree instead of scrolling away with it, and section headers stay visible while their content scrolls. Scrollbars in the sidebar appear only while the pointer is over a section.

## Install or update

**Mac:** install `coflux-2.28.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.28.0
cofluxd update
```

## Upgrade impact

- Desktop app only. The center, the runtime and the iOS app are unchanged, and devices and headless hosts need no action.
