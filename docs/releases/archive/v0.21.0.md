### Features

- Drive workspace activity from hooks and add a dedicated local Postgres instance.

## Upgrade

- **daemon**: The center automatically upgrades online devices; workers hot-swap after signature verification. No manual action is required.
- **cofluxd CLI**: Run `npm i -g cofluxd@latest` (`0.6.0` → `0.7.0`).
