### Features

- **web**: Return Clawd to its seated pose after the completed state is viewed rather than celebrating indefinitely.
- **web**: Animate terminal-tab Clawd from original-site frames instead of a static silhouette, with three agent-state poses.
- **server**: Add a P2P master switch, initially disabled in production as mitigation.
- **web**: Show one cold-start logo overlay from initial HTML through the first snapshot.
- **web**: Add optimistic terminal tabs and workspace rows, visible/selected next frame and reconciled in place by broadcasts.
- **ios**: Add the device panel with fleet transport paths, RTT, and versions (plan 077).
- **proxy**: Flatten previews to {shortId}-p.coflux.dev.

### Fixes

- **daemon**: Do not mark turns complete while background work remains in flight; mark work active as soon as a prompt is submitted.
- **web**: Use the gym animation's first standing frame as Clawd's default pose.
- **client**: Back off after P2P failures to prevent repeated relay/P2P oscillation.
- **client**: Use heartbeats for liveness; remove channels after two unanswered probes and fall back to relay.
- **client**: Recover silently dead control connections when sent messages receive no response.
- Revert an earlier silent-WS-recovery change and its follow-up fixes; route watchdog death through onclose and automatically reconnect initial connections with existing tokens.
- **web**: Align plan 078 comments with actual persistence and clean pending timers on unmount.

### Refactoring and internal changes

- **client**: Inject clocks and sockets into connection handling for deterministic tests of existing behavior.
