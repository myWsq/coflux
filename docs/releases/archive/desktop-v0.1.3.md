Coflux desktop v0.1.3 for macOS 26+ on Apple Silicon.

- **Install**: Download the DMG and drag Coflux into Applications. The app is signed and notarized by Apple.
- **Automatic updates**: The app reads latest-mac.yml from this repository’s desktop-updates branch and downloads installers from this Release.
- **Version compatibility**: Admission uses the control-plane protocol version (plan 105). Routine center deployments do not disconnect older desktop versions; only breaking protocol changes require an update.
