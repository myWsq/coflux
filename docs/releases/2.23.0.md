# Coflux 2.23.0

**Hover a Claude terminal tab to see where its session stands, and give your account a speech-recognition key for dictation in the iOS app.**

In 2.23.0:

- **Session recap on terminal tabs.** Hovering a tab that runs Claude Code shows the recap Claude writes for its own session: what it was doing and where it stopped. Claude writes it a few minutes after a session goes idle; the card hides as soon as a new turn starts, so it never describes a turn that has moved on.
- **Speech recognition key.** Settings has a new Speech recognition section where you store an account-level Doubao Seed-ASR 2.0 API key. The center keeps it encrypted, and the Coflux iOS app uses it for dictation, with the agent's recent conversation as context so project words and names come out right. The key is never shown again after you save it; you can replace or remove it.
- **Remote screen reconnects.** The screen helper on the controlled Mac now runs an AppKit event loop, so it sees the virtual display it creates come online. A remote screen that was closed, reopened or resized keeps streaming instead of timing out. This completes the fix started in 2.19.2.

## iOS app

The iOS app is built from source and is not part of this release's downloads. This version of the source is redesigned for iPhone Duo (outer display, inner display open wide and open tall, Split View), switches terminals from a pile of agent avatars, names each terminal by what its agent is doing, scrolls full-screen terminal programs with a one-finger swipe, and dictates through Seed-ASR with the key above.

## Install or update

**Mac:** install `coflux-2.23.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.23.0
cofluxd update
```

## Upgrade impact

- The center was updated before this release. It adds migration 11, which stores the encrypted speech-recognition keys; the migration is one-way, so an older center does not start on the migrated database.
- The session recap, the Speech recognition settings and the remote screen fix come with the desktop app. Update the desktop app on the Mac you look from for the first two, and on the controlled Mac for the remote screen.
- Devices and headless hosts need no action: the runtime is unchanged apart from its protocol definitions.
