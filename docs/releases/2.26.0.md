# Coflux 2.26.0

**The top of the desktop sidebar now lists the agents you are running, one row per terminal.**

In 2.26.0:

- **Agent terminals at the top of the sidebar.** The section at the top of the desktop sidebar now lists every terminal with a running agent (working, waiting for approval, waiting for an answer, stopped on an error, or finished its turn), including terminals in a device's home directory. Each row shows the agent's logo, the terminal's title (the conversation topic when the agent sets one), the project and branch or the device it runs on, and its status. Two agents in one workspace are two rows. Rows keep the project tree's order and never move when an agent changes state; a row disappears when its agent exits. Hover a row for the full title, the agent's message or progress, and the workspace path; click it to land on that terminal, which is highlighted while it is on screen.
- **Command-Shift-A visits each waiting terminal.** The shortcut now cycles through waiting terminals rather than workspaces, so two agents waiting in the same workspace are two stops, and terminals in a device's home directory are reached too.
- The recently visited workspaces that 2.25.0 listed in this section are gone; the Command-P palette keeps its recent places. The project tree is unchanged.

## Install or update

**Mac:** install `coflux-2.26.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.26.0
cofluxd update
```

## Upgrade impact

- Desktop app only. The center, the runtime and the iOS app are unchanged, and devices and headless hosts need no action.
