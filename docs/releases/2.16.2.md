# Coflux 2.16.2

**Annotation boxes, labels and pins stand out on every page.**

In the built-in browser's annotate mode, the hover box and its label, the selected and region boxes, the outlines and the numbered pins followed the app theme's accent, which is a shade of grey. On many pages they were close to invisible, for example light boxes on a white page in dark appearance. They are now drawn in a fixed magenta with white text and a thin white ring around every box, and a pin turns green with a check mark once an agent has resolved it. The number badges in the annotation panel and cards use the same colours as their pins. The colours no longer change with the app's light or dark appearance.

Comments on diff lines in the files view keep their current colours.

## Install or update

**Mac:** install `coflux-2.16.2-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.16.2
cofluxd update
```

## Upgrade impact

- Desktop only: update the app to see the new colours. Headless hosts gain nothing from this release and need no action.
- No center, protocol or configuration change.
