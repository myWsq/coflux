# Coflux 2.27.0

**Jumping to a terminal now shows you where you are: the sidebar expands the workspace's project and scrolls its row into view.**

In 2.27.0:

- **The sidebar follows you to the terminal you jump to.** Landing on a terminal — from a system notification, a row in the sidebar's current-agents section, Command-Shift-A, or the Command-P palette — expands the workspace's project in the sidebar when it is collapsed and scrolls the workspace row into view. A row that is already visible does not move. The same happens for the selection restored at startup, and jumps that land on a device detail view scroll that device's row. The expansion sticks like a manual one (it survives a restart), and collapsing the project by hand afterwards is respected until the next jump. A sidebar hidden with Command-B stays hidden; it reveals the selection when you show it again.

## Install or update

**Mac:** install `coflux-2.27.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.27.0
cofluxd update
```

## Upgrade impact

- Desktop app only. The center, the runtime and the iOS app are unchanged, and devices and headless hosts need no action.
