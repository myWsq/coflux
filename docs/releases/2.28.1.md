# Coflux 2.28.1

**A finished agent turn you have looked at stays looked at: the mark now survives reconnects and restarts, and never hides a newer turn.**

In 2.28.1:

- **The "seen" mark is stored.** Once any of your clients has had a finished turn on screen, the celebration stops on every client and stays stopped. Previously the mark lived only in the center's memory and was lost whenever a device reconnected or the center restarted, so every finished terminal celebrated again.
- **A turn finished while a device was unreachable is not mistaken for the one you saw.** Each agent status now carries the moment its state was entered. If an agent ran a whole further turn while its device was disconnected from the center, that turn comes back as unseen.

## Install or update

**Mac:** install `coflux-2.28.1-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.28.1
cofluxd update
```

## Upgrade impact

- The runtime changed; the center pushes it to devices automatically and terminals keep running. The launcher, `ptyd` and the CLI are unchanged, so headless hosts need no manual step.
- The center was deployed ahead of this release with schema migrations 14 and 15 (`agent_seen` and its `state_since` column). Both are one-way: a center rolled back to an earlier build refuses the migrated database.
- Marks made before the center deployment were never stored and are not recovered: each already-finished terminal celebrates once more. A terminal marked before its device received this runtime may also be shown as unseen once after the update.
- An older runtime keeps working against the new center with the previous behavior until it updates.
- The desktop and iOS apps only receive regenerated protocol code.
