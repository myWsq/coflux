# Security

Please report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/myWsq/coflux/security/advisories/new), rather than a public issue.

Include the affected version, operating system, a minimal reproduction, and the impact you observed. Do not include real credentials, private signing keys, or unrelated user data.

Coflux can execute commands on connected devices. Protect your account, local credentials, and any self-hosted control plane accordingly. Report suspected account-boundary bypasses, unauthorized terminal access, or signature-verification failures privately.

Security fixes target the latest stable release. Older releases may require an upgrade; no response-time or backport guarantee is currently offered.
